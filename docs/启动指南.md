## 1. 一键启动（推荐）

在项目根目录 `D:/Demo/payment_analytics/` 执行：

```bash
# 完整流程：造数 → 入库 → 建模 → 测试（首次 / 数据想重刷时）
python scripts/run_pipeline.py

# 数据已存在、只想重建数仓时（跳过 1 分钟的造数）
python scripts/run_pipeline.py --skip-gen

# 加 --docs 额外生成血缘文档
python scripts/run_pipeline.py --docs

# 启动后跑示例分析查询
python scripts/query_demo.py
```

脚本会依次打印每步耗时，任何一步失败即中止并提示。

## 2. 分步启动（手动，适合讲解 / 调试）

### 前置条件
```bash
# Python ≥3.10，安装依赖
pip install duckdb dbt-core dbt-duckdb pandas

# Windows 中文控制台：让 Python 默认 UTF-8（否则 dbt 读中文注释会报 gbk 错误）
# 建议：在每个新终端先执行一次
export PYTHONUTF8=1

# 验证
python --version
dbt --version        # 应显示 dbt-core + duckdb 插件
```

### 第 1 步：造数（生成原始 CSV）
```bash
python scripts/gen_data.py
# 产出：data/payments.csv（~50 万行）、users/merchants/currencies/currency_rates
# 末尾会打印"脏数据体检"：重复/空值/非法状态/乱序各多少行
```

### 第 2 步：入库（CSV → DuckDB bronze 层）
```bash
python scripts/load_to_bronze.py
# 验证：bronze.raw_payments 502,500 行、raw_users 50,000 行、raw_merchants 2,000 行…
```

### 第 3 步：建模（dbt 四层数仓）
```bash
dbt run
# 验证：Finished ... PASS=24（5 bronze 视图 + 5 silver 表 + 4 dim + 1 fct + 9 marts）
```

### 第 4 步：数据质量测试
```bash
dbt test
# 验证：PASS=52 WARN=0 ERROR=0
```

### 第 5 步：血缘图 / 文档
```bash
dbt docs generate   # 生成 target/catalog.json
dbt docs serve      # 浏览器打开 http://localhost:8080 查看血缘图（Ctrl+C 停止）
```

### 第 6 步：示例分析（可选，看项目产出）
```bash
python scripts/query_demo.py
```

## 3. 常用验证查询（直接用 DuckDB 查）

```bash
python -c "
import duckdb
con = duckdb.connect('analytics.duckdb')
print(con.execute('SELECT count(*) FROM main_gold.fct_payments').fetchone())
"
```

| 想验证什么 | SQL |
|---|---|
| 事实表行数 | `SELECT count(*) FROM main_gold.fct_payments` |
| 星型 join 后按日 GMV | `SELECT date_day, sum(gmv_usd) FROM main_marts.daily_payment_summary GROUP BY 1 ORDER BY 1 DESC LIMIT 7` |
| 清洗量 | `SELECT * FROM main_marts.data_quality_audit` |
| 最新 KPI + 环比 | `SELECT * FROM main_marts.daily_kpi ORDER BY date_day DESC LIMIT 7` |
| 血缘图 | `dbt docs serve` → localhost:8080 |

## 5. 常见问题（踩坑速查）

| 现象 | 原因 / 解决 |
|---|---|
| `UnicodeDecodeError: 'gbk' codec` | 中文 Windows 默认 GBK。`export PYTHONUTF8=1` 后再跑 |
| `dbt: command not found` | dbt 不在 PATH。用 `python -m pip install dbt-core dbt-duckdb` 装到 Python Scripts；或直接运行一键脚本（自动查找 dbt.exe） |
| 想重刷全部数据 | 删掉 `data/` 和 `analytics.duckdb`，再 `python scripts/run_pipeline.py` |
| 只想重建数仓不动原始数据 | `python scripts/run_pipeline.py --skip-gen` |
| 血缘图打不开 | 先 `dbt docs generate` 再 `dbt docs serve` |
